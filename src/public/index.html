Store Rating Platform — API Reference

A role-based REST API for the Store Rating Platform coding challenge. Three roles — System Administrator, Normal User, and Store Owner — share a single JWT login and get different capabilities based on their role. This page documents every endpoint with live request/response examples you can try directly from your browser against this running server.

🔐 Authentication

Registration and login are open to everyone. Every other endpoint requires an Authorization: Bearer <token> header.

POST /api/v1/auth/register Public

Creates a Normal User account. Name must be 20–60 characters, password 8–16 characters with 1 uppercase & 1 special character.

Request body
{
  "name": "Amol Jagdish Kakde 12345",
  "email": "amol@gmail.com",
  "password": "User@123",
  "address": "123 Main Street, New York"
}
Response · 201
{
  "success": true,
  "message": "User registered successfully",
  "data": { "id": 3, "name": "...", "email": "amol@gmail.com" }
}
Generates a unique email each click 

      

    


    

      

        POST
        /api/v1/auth/login
        Public
      

      

        
Returns a JWT valid for the role stored on the user (Admin / User / StoreOwner). Store the token and send it as Authorization: Bearer <token>.

        

          
Request body

            
{
  "email": "amol@gmail.com",
  "password": "User@123"
}

          

          
Response · 200

            
{
  "success": true,
  "message": "Login successful",
  "data": { "token": "eyJhbGciOi...", "user": { "id": 3, "role": "User" } }
}

          

        

      

    


    

      

        GET
        /api/v1/auth/profile
        🔒 Any logged-in user
      

      

        
Returns the profile of the currently authenticated user (password field excluded).

        
Response · 200

        
{
  "success": true,
  "data": { "user": { "id": 3, "name": "...", "email": "...", "address": "...", "role": "User", "createdAt": "...", "updatedAt": "..." } }
}

      

    


    

      

        PATCH
        /api/v1/auth/password
        🔒 Any logged-in user
      

      

        
Requires the correct current password. New password follows the same strength rule as registration.

        
Request body

        
{ "currentPassword": "User@123", "newPassword": "Pass@456" }

      

    

  


  
  

    
🏬 Stores & Ratings

    
Available to any authenticated user (Normal User, Store Owner, or Admin).


    

      

        GET
        /api/v1/stores
        🔒 Authenticated
      

      

        
Supports pagination, search (by name/address), and sorting. userRating reflects the caller's own submitted rating, if any.

        
Query params

        
?search=market&page=1&limit=10&sortBy=name&sortOrder=ASC

        
Response · 200

        
{
  "success": true,
  "data": {
    "items": [{ "id": 1, "name": "Central Market Downtown", "address": "...", "overallRating": "4.5", "userRating": 5 }],
    "pagination": { "page": 1, "limit": 20, "totalItems": 1, "totalPages": 1 }
  }
}

      

    


    

      

        POST
        /api/v1/stores/:storeId/ratings
        🔒 Authenticated
      

      

        
Submits a rating (1–5). Calling it again for the same store updates the existing rating instead of creating a duplicate — enforced by a unique (userId, storeId) index.

        
Request body

        
{ "rating": 5 }

      

    

  


  
  

    
🛡️ Admin

    
Restricted to users with role Admin. Requests from other roles receive 403 Insufficient permissions.


    

      
GET/api/v1/admin/dashboard🔒 Admin

      

        
{ "success": true, "data": { "totalUsers": 4, "totalStores": 3, "totalRatings": 12 } }

      

    


    

      
POST/api/v1/admin/users🔒 Admin

      

        
Role must be one of Admin, User, StoreOwner.

        
{
  "name": "rohan Sanjay ghuge store owner",
  "email": "ehgt@example.com",
  "password": "Ehgt@123",
  "address": "789 Business Avenue",
  "role": "StoreOwner"
}

      

    


    

      
GET/api/v1/admin/users🔒 Admin

      

        
Filter with ?name=&email=&address=&role= and sort with ?sortBy=&sortOrder=.

      

    


    

      
GET/api/v1/admin/users/:userId🔒 Admin

      
If the user is a Store Owner, their store's average rating is included under managedStore.averageRating.

    


    

      
POST/api/v1/admin/stores🔒 Admin

      

        
{
  "name": "Central Market Downtown",
  "email": "store@example.com",
  "address": "456 Market Street, New York",
  "ownerId": 4
}

      

    


    

      
GET/api/v1/admin/stores🔒 Admin

      
Returns every store with its computed overall rating.

    

  


  
  

    
🧑‍💼 Store Owner

    
Restricted to role StoreOwner. A store owner may only view ratings for a store they own.


    

      
GET/api/v1/owner/stores/:storeId/ratings🔒 Store Owner

      

        
{
  "success": true,
  "data": {
    "store": { "id": 1, "name": "Central Market Downtown", ... },
    "averageRating": 4.5,
    "ratings": [{ "id": 1, "rating": 5, "user": { "id": 1, "name": "...", "email": "..." } }]
  }
}
